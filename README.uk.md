# ficbook-downloader

[English](README.md) | [Русский](README.ru.md) | Українська

Консольна програма і вікно для macOS і Windows. Зберігає твори з [ficbook.net](https://ficbook.net/) у текст UTF-8, EPUB і FB2.

Ви передаєте посилання на роботи. Програма відкриває публічну сторінку твору, проходить списком частин і записує по одному файлу кожного формату. Кожна частина стає окремим розділом. У файлі є автор, перекладач, назва і номер серії, фендом, мітки й опис. Якщо в роботи є обкладинка, вона теж потрапляє у файл. Між запитами програма чекає. Браузер не потрібен.

Звичайним HTTP-бібліотекам ficbook відповідає перевіркою безпеки. Ця програма використовує [curl_cffi](https://github.com/lexiforest/curl_cffi), щоб запит виглядав як звичайне з'єднання браузера і у відповідь приходила публічна сторінка твору.

## Завантажити для Mac

Завантажте [Ficbook-Downloader.dmg](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.dmg). Цей файл для Mac із процесором Apple silicon.

1. Відкрийте образ диска.
2. Перетягніть **Ficbook Downloader** у теку Applications.
3. Відкрийте програму з Applications.

Під час першого запуску може з’явитися вікно **"Ficbook Downloader" Not Opened**: Apple could not verify "Ficbook Downloader". Натисніть **Done**. Кнопку **Move to Trash** не натискайте. Потім відкрийте Термінал і виконайте:

```bash
xattr -dr com.apple.quarantine "/Applications/Ficbook Downloader.app"
```

Знову відкрийте програму з Applications. Попередження більше не з’явиться.

## Завантажити для Windows

Завантажте [Ficbook-Downloader.exe](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.exe) і запустіть його подвійним клацанням.

Windows може показати попередження SmartScreen, бо файл не підписаний. Натисніть **Докладніше**, потім **Виконати попри це**.

## Встановлення з джерельного коду

```bash
cd ~/Developer/ficbook-downloader
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

Якщо каталог проєкту вже є і оточення створене, достатньо активувати його:

```bash
cd ~/Developer/ficbook-downloader
source .venv/bin/activate
```

Встановлення просто зі сховища:

```bash
pip install git+https://github.com/thanaton20/ficbook-downloader.git
```

## Вікно

Завантажена програма відкриває це вікно. Якщо ставили з джерельного коду, запустіть:

```bash
ficbook-gui
```

На Windows, з теки проєкту:

```bat
.venv\Scripts\activate
ficbook-gui
```

Те саме вікно відкривається командою `ficbook-dl --gui`. Ліворуч три сторінки: **Завантажити**, **Бібліотека** і **Про автора**. Унизу бічної панелі кнопки **EN**, **RU** і **UK** перемикають мову. Вибір запам'ятовується. Підписи в текстовому файлі, наприклад «Автор» і «Серія», теж залежать від неї. У командному рядку те саме роблять `--lang en`, `--lang ru` і `--lang uk`.

### Завантажити

1. У полі **Посилання на роботи** вставте по одному посиланню в рядок. Підійде і номер роботи. Посилання на одну частину все одно зберігає весь твір.
2. **Зберегти в** — тека `Stories` у домашньому каталозі. **Огляд** вибирає іншу теку.
3. **TXT**, **EPUB** і **FB2** увімкнені одразу. Натисніть формат, щоб вимкнути його.
4. **Пауза (секунди)** — пауза між запитами. Спочатку там `1.5`.
5. Натисніть **Завантажити**. Кнопка зміниться на **Зупинити**. У журналі друкується кожна частина, а потім рядок про збереження для кожного файла.

**Зупинити** зупиняє завантаження перед наступною частиною. Уже записані файли залишаються на місці. Кожна робота зберігається як `Назва — Автор` із залишеними розширеннями.

### Бібліотека

Вставте посилання на автора, наприклад `https://ficbook.net/authors/2`, і натисніть **Показати книги**. На сторінці буде список книг цього автора. **Завантажити** в рядку зберігає цю книгу в теку і формати, обрані на сторінці «Завантажити». **Перегляд** відкриває назву книги, ім'я автора, назву серії й обкладинку.

## Командний рядок

```bash
ficbook-dl --lang uk https://ficbook.net/readfic/1
ficbook-dl 1 13340733 -o ~/Stories --delay 2 --format epub,fb2
```

Підійде і посилання на окрему частину. Адреса вигляду `https://ficbook.net/readfic/<id>/<part>` усе одно зберігає весь твір. Можна передати і сам номер роботи, без повної адреси.

Файли потрапляють у теку `stories/`, якщо не вказано `--out`. `--format` приймає `txt`, `epub` і `fb2`. Типово створюються всі три. Ім'я файла: `Назва — Автор.txt`, `.epub` і `.fb2`.

`--out` задає теку. `--delay` — пауза між запитами в секундах. Типово 1,5 секунди. `--lang` задає мову: `en`, `ru` або `uk`.

Поки триває завантаження, у терміналі друкується кожна частина, а наприкінці рядок про збереження.

Текстовий файл українською виглядає так:

```
Назва
Автор: Ім'я
https://ficbook.net/readfic/<id>
Серія: Назва серії (2)
Фендом: ...
PG-13 · Завершено
Мітки: ...

Опис

Назва частини

Текст частини
```

Наступного разу відкрийте термінал, перейдіть у теку проєкту і знову виконайте `source .venv/bin/activate`, потім `ficbook-gui`. Коли оточення активне, на початку рядка запрошення зазвичай видно `(.venv)`.

## Обмеження

Текст має бути доступний на публічній сторінці. Якщо сайт показує перевірку віку або в частини немає тексту, цю роботу пропущено, і програма переходить до наступного посилання. Залишайте паузу між запитами, щоб не навантажувати сайт. Пауза типово — 1,5 секунди.
