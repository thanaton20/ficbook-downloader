# ficbook-downloader

[English](README.md) | [Русский](README.ru.md) | Українська

Програма для комп'ютера, телефона й командного рядка. Зберігає твори з [ficbook.net](https://ficbook.net/) у текст UTF-8, EPUB і FB2. Працює на macOS, Windows, iPhone і Android, а на Linux — з джерельного коду.

Ви передаєте посилання на роботи. Програма відкриває публічну сторінку твору, проходить списком частин і записує по одному файлу кожного формату. Кожна частина стає окремим розділом. У файлі є автор, перекладач, назва і номер серії, фендом, мітки й опис. Якщо в роботи є обкладинка, вона теж потрапляє у файл. Між запитами програма чекає. Браузер не потрібен.

Звичайним HTTP-бібліотекам ficbook відповідає перевіркою безпеки. Програма для комп'ютера і командний рядок використовують [curl_cffi](https://github.com/lexiforest/curl_cffi), щоб запит виглядав як звичайне з'єднання браузера і у відповідь приходила публічна сторінка твору. Застосунки для телефона натомість відкривають кожну сторінку у вбудованому браузері телефона.

## Завантажити для Mac

Завантажте [Ficbook-Downloader.dmg](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.dmg). Ця збірка для Mac на Apple silicon. На Mac з Intel скористайтеся [встановленням з джерельного коду](#встановлення-з-джерельного-коду).

1. Відкрийте образ диска.
2. Перетягніть **Ficbook Downloader** у теку «Програми».
3. Запустіть застосунок із «Програм».

Під час першого запуску macOS може показати вікно **«Ficbook Downloader» не відкрито** з текстом, що Apple не вдалося перевірити застосунок. Натисніть **Готово**. Не натискайте **Перемістити до кошика**. Потім відкрийте Термінал і виконайте:

```bash
xattr -dr com.apple.quarantine "/Applications/Ficbook Downloader.app"
```

Знову відкрийте застосунок із «Програм». Попередження більше не буде.

Щоб оновити, завантажте новий образ і знову перетягніть застосунок у «Програми», замінивши старий.

## Завантажити для Windows

Завантажте [Ficbook-Downloader.exe](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.exe) і запустіть його подвійним клацанням.

Windows може показати попередження SmartScreen, бо файл не підписаний. Натисніть **Докладніше**, потім **Виконати попри це**.

Файл для Windows поки що версії 0.3.0. У ньому ще немає нового оформлення, нумерації посилань і переглядів книжок. Щоб отримати їх зараз, скористайтеся [встановленням з джерельного коду](#встановлення-з-джерельного-коду).

## Завантажити для iPhone

Застосунку для iPhone немає в App Store. Його встановлюють з комп'ютера через [Sideloadly](https://sideloadly.io) зі своїм Apple ID.

1. Встановіть [Sideloadly](https://sideloadly.io) на Mac або ПК з Windows.
2. Завантажте на цей комп'ютер [Ficbook-Downloader.ipa](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.ipa).
3. Під'єднайте iPhone кабелем. Перетягніть **Ficbook-Downloader.ipa** у Sideloadly, введіть свій Apple ID і натисніть **Start**.
4. На iPhone відкрийте **Параметри › Приватність і безпека › Режим розробника**, увімкніть його й перезавантажте телефон, коли він попросить.
5. Відкрийте **Параметри › Загальні › VPN і керування пристроєм**, торкніться свого Apple ID і натисніть **Довіряти**.
6. Відкрийте **Ficbook Downloader** на головному екрані.

Потрібна iOS 16.4 або новіша. З безкоштовним Apple ID застосунок перестає відкриватися через 7 днів — встановіть його через Sideloadly ще раз, щоб продовжити. Підійде і AltStore. Збережені книжки лежать у **Файли › На iPhone › Ficbook Downloader**.

## Завантажити для Android

1. Завантажте на телефоні [Ficbook-Downloader.apk](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.apk).
2. Відкрийте завантажений файл. Якщо Android запитає, дозвольте браузеру або застосунку «Файли» встановлювати невідомі застосунки, потім поверніться й натисніть **Встановити**.
3. Якщо Google Play Захист попередить, що застосунок невідомий, натисніть **Докладніше**, потім **Усе одно встановити**.

Потрібен Android 10 або новіший. Збережені книжки лежать у **Завантаження › Ficbook**. Новий `Ficbook-Downloader.apk` встановлюється поверх старого.

Застосунки для телефона відкривають сторінки ficbook у вбудованому браузері телефона. Якщо ficbook покаже перевірку безпеки або підтвердження віку, застосунок покаже цю сторінку, щоб ви її пройшли. Як вони влаштовані — у [mobile/README.md](mobile/README.md).

## Встановлення з джерельного коду

Так можна встановити на macOS (Intel або Apple silicon), Windows і Linux. Потрібні Python 3.11 або новіший і Git.

На macOS або Linux:

```bash
git clone https://github.com/thanaton20/ficbook-downloader.git
cd ficbook-downloader
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

На Windows:

```bat
git clone https://github.com/thanaton20/ficbook-downloader.git
cd ficbook-downloader
py -m venv .venv
.venv\Scripts\activate
pip install -e .
```

На Linux вікну потрібен Tk. На Debian або Ubuntu виконайте `sudo apt install python3-tk`, на Fedora — `sudo dnf install python3-tkinter`.

Потім `ficbook-gui` відкриває вікно, а `ficbook-dl` запускає командний рядок. Встановлення без клонування:

```bash
pip install git+https://github.com/thanaton20/ficbook-downloader.git
```

## Вікно

Завантажена програма відкриває це вікно. Якщо ставили з джерельного коду, запустіть:

```bash
ficbook-gui
```

На Windows, з теки проєкту:

```bat
.venv\Scripts\activate
ficbook-gui
```

Те саме вікно відкривається командою `ficbook-dl --gui`. Ліворуч три сторінки: **Завантажити**, **Бібліотека** і **Про автора**. Унизу бічної панелі кнопки **EN**, **RU** і **UK** перемикають мову. Вибір запам'ятовується. Підписи в текстовому файлі, наприклад «Автор» і «Серія», теж залежать від неї. У командному рядку те саме роблять `--lang en`, `--lang ru` і `--lang uk`.

### Завантажити

1. У полі **Посилання на роботи** вставте по одному посиланню в рядок. Підійде і номер роботи. Посилання на одну частину все одно зберігає весь твір. Кожне посилання отримує номер — його місце в черзі завантаження, а під полем з'являється перегляд з обкладинкою, назвою й автором. У робіт без обкладинки назва пишеться на кольоровому блоці.
2. **Зберегти в** — тека `Stories` у домашньому каталозі. **Огляд** вибирає іншу теку, і цей вибір зберігається під час наступного запуску.
3. **TXT**, **EPUB** і **FB2** увімкнені одразу. Натисніть формат, щоб вимкнути його.
4. **Пауза (секунди)** — пауза між запитами. Спочатку там `1.5`.
5. Натисніть **Завантажити**. Кнопка зміниться на **Зупинити**. У журналі друкується кожна частина, а потім рядок про збереження для кожного файла.

**Зупинити** зупиняє завантаження перед наступною частиною. Уже записані файли залишаються на місці. Кожна робота зберігається як `Назва — Автор` із залишеними розширеннями.

### Бібліотека

Вставте посилання на автора, наприклад `https://ficbook.net/authors/2`, і натисніть **Показати книги**. На сторінці буде список книг цього автора. **TXT**, **EPUB** і **FB2** на цій сторінці обирають тип файла. Над сіткою обкладинок — фото й ім'я автора. **Завантажити** під книгою зберігає її в обраних типах, у теку зі сторінки «Завантажити». Натисніть на обкладинку, щоб побачити назву книги, ім'я автора, назву серії й більшу обкладинку.

## Командний рядок

```bash
ficbook-dl --lang uk https://ficbook.net/readfic/1
ficbook-dl 1 13340733 -o ~/Stories --delay 2 --format epub,fb2
```

Підійде і посилання на окрему частину. Адреса вигляду `https://ficbook.net/readfic/<id>/<part>` усе одно зберігає весь твір. Можна передати і сам номер роботи, без повної адреси.

Файли потрапляють у теку `stories/`, якщо не вказано `--out`. `--format` приймає `txt`, `epub` і `fb2`. Типово створюються всі три. Ім'я файла: `Назва — Автор.txt`, `.epub` і `.fb2`.

`--out` задає теку. `--delay` — пауза між запитами в секундах. Типово 1,5 секунди. `--lang` задає мову: `en`, `ru` або `uk`.

Поки триває завантаження, у терміналі друкується кожна частина, а наприкінці рядок про збереження.

Текстовий файл українською виглядає так:

```
Назва
Автор: Ім'я
https://ficbook.net/readfic/<id>
Серія: Назва серії (2)
Фендом: ...
PG-13 · Завершено
Мітки: ...

Опис

Назва частини

Текст частини
```

Наступного разу відкрийте термінал, перейдіть у теку проєкту і знову виконайте `source .venv/bin/activate`, потім `ficbook-gui`. Коли оточення активне, на початку рядка запрошення зазвичай видно `(.venv)`.

## Обмеження

Текст має бути доступний на публічній сторінці. На комп'ютері, якщо сайт показує перевірку віку або в частини немає тексту, цю роботу пропущено, і програма переходить до наступного посилання. На телефоні застосунок показує перевірку віку, щоб ви її підтвердили. Залишайте паузу між запитами, щоб не навантажувати сайт. Пауза типово — 1,5 секунди.
