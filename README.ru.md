# ficbook-downloader

[English](README.md) | Русский | [Українська](README.uk.md)

Программа для компьютера, телефона и командной строки. Сохраняет рассказы с [ficbook.net](https://ficbook.net/) в текст UTF-8, EPUB и FB2. Работает на macOS, Windows, iPhone и Android, а на Linux — из исходников.

Вы передаёте ссылки на работы. Программа открывает публичную страницу рассказа, проходит по списку частей и записывает по одному файлу каждого формата. Каждая часть становится отдельной главой. В файле есть автор, переводчик, название и номер серии, фэндом, метки и описание. Если у работы есть обложка, она тоже попадает в файл. Между запросами программа ждёт. Браузер не нужен.

Обычным HTTP-библиотекам ficbook отвечает проверкой безопасности. Программа для компьютера и командная строка используют [curl_cffi](https://github.com/lexiforest/curl_cffi), чтобы запрос выглядел как обычное соединение браузера и в ответ приходила публичная страница рассказа. Приложения для телефона вместо этого открывают каждую страницу во встроенном браузере телефона.

## Скачать для Mac

Скачайте [Ficbook-Downloader.dmg](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.dmg). Эта сборка для Mac на Apple silicon. На Mac с Intel используйте [установку из исходников](#установка-из-исходников).

1. Откройте образ диска.
2. Перетащите **Ficbook Downloader** в папку «Программы».
3. Запустите приложение из «Программ».

При первом запуске macOS может показать окно **«Ficbook Downloader» не открыто** с текстом, что Apple не удалось проверить приложение. Нажмите **Готово**. Не нажимайте **Переместить в корзину**. Затем откройте Терминал и выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Ficbook Downloader.app"
```

Снова откройте приложение из «Программ». Предупреждения больше не будет.

Чтобы обновить, скачайте новый образ и снова перетащите приложение в «Программы», заменив старое.

## Скачать для Windows

Скачайте [Ficbook-Downloader.exe](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook-Downloader.exe) и запустите его двойным щелчком.

Windows может показать предупреждение SmartScreen, потому что файл не подписан. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

Файл для Windows пока версии 0.3.0. В нём ещё нет нового оформления, нумерации ссылок и превью книг. Чтобы получить их сейчас, используйте [установку из исходников](#установка-из-исходников).

## Скачать для iPhone

Приложения для iPhone нет в App Store. Его устанавливают с компьютера через [Sideloadly](https://sideloadly.io) со своим Apple ID.

1. Установите [Sideloadly](https://sideloadly.io) на Mac или ПК с Windows.
2. Скачайте на этот компьютер [Ficbook.ipa](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook.ipa).
3. Подключите iPhone кабелем. Перетащите **Ficbook.ipa** в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone откройте **Настройки › Конфиденциальность и безопасность › Режим разработчика**, включите его и перезагрузите телефон, когда он попросит.
5. Откройте **Настройки › Основные › VPN и управление устройством**, нажмите на свой Apple ID и нажмите **Доверять**.
6. Откройте **Ficbook** на главном экране.

Нужна iOS 16.4 или новее. С бесплатным Apple ID приложение перестаёт открываться через 7 дней — установите его через Sideloadly ещё раз, чтобы продлить. Подойдёт и AltStore. Сохранённые книги лежат в **Файлы › На iPhone › Ficbook**.

## Скачать для Android

1. Скачайте на телефоне [Ficbook.apk](https://github.com/thanaton20/ficbook-downloader/releases/latest/download/Ficbook.apk).
2. Откройте скачанный файл. Если Android спросит, разрешите браузеру или приложению «Файлы» устанавливать неизвестные приложения, затем вернитесь и нажмите **Установить**.
3. Если Google Play Защита предупредит, что приложение неизвестное, нажмите **Подробнее**, затем **Всё равно установить**.

Нужен Android 10 или новее. Сохранённые книги лежат в **Загрузки › Ficbook**. Новый `Ficbook.apk` устанавливается поверх старого.

Приложения для телефона открывают страницы ficbook во встроенном браузере телефона. Если ficbook покажет проверку безопасности или подтверждение возраста, приложение покажет эту страницу, чтобы вы её прошли. Как они устроены — в [mobile/README.md](mobile/README.md).

## Установка из исходников

Так можно установить на macOS (Intel или Apple silicon), Windows и Linux. Нужны Python 3.11 или новее и Git.

На macOS или Linux:

```bash
git clone https://github.com/thanaton20/ficbook-downloader.git
cd ficbook-downloader
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

На Windows:

```bat
git clone https://github.com/thanaton20/ficbook-downloader.git
cd ficbook-downloader
py -m venv .venv
.venv\Scripts\activate
pip install -e .
```

На Linux окну нужен Tk. На Debian или Ubuntu выполните `sudo apt install python3-tk`, на Fedora — `sudo dnf install python3-tkinter`.

Потом `ficbook-gui` открывает окно, а `ficbook-dl` запускает командную строку. Установка без клонирования:

```bash
pip install git+https://github.com/thanaton20/ficbook-downloader.git
```

## Окно

Скачанная программа открывает это окно. Если ставили из исходников, запустите:

```bash
ficbook-gui
```

На Windows, из папки проекта:

```bat
.venv\Scripts\activate
ficbook-gui
```

Та же форма открывается командой `ficbook-dl --gui`. Слева три страницы: **Скачать**, **Библиотека** и **Об авторе**. Внизу боковой панели кнопки **EN**, **RU** и **UK** переключают язык. Выбор запоминается. Подписи в текстовом файле, например «Автор» и «Серия», тоже зависят от него. В командной строке то же самое делают `--lang en`, `--lang ru` и `--lang uk`.

### Скачать

1. В поле **Ссылки на работы** вставьте по одной ссылке в строку. Подойдёт и номер работы. Ссылка на одну часть всё равно сохраняет весь рассказ. Каждая ссылка получает номер — её место в очереди скачивания, а под полем появляется превью с обложкой, названием и автором. У работ без обложки название пишется на цветном блоке.
2. **Сохранить в** — папка `Stories` в домашнем каталоге. **Обзор** выбирает другую папку, и этот выбор сохраняется при следующем запуске.
3. **TXT**, **EPUB** и **FB2** включены сразу. Нажмите формат, чтобы отключить его.
4. **Пауза (секунды)** — пауза между запросами. Сначала там `1.5`.
5. Нажмите **Скачать**. Кнопка сменится на **Стоп**. В журнале печатается каждая часть, а затем строка о сохранении для каждого файла.

**Стоп** останавливает загрузку перед следующей частью. Уже записанные файлы остаются на месте. Каждая работа сохраняется как `Название — Автор` с оставшимися расширениями.

### Библиотека

Вставьте ссылку на автора, например `https://ficbook.net/authors/2`, и нажмите **Показать книги**. На странице будет список книг этого автора. **TXT**, **EPUB** и **FB2** на этой странице выбирают тип файла. Над сеткой обложек — фото и имя автора. **Скачать** под книгой сохраняет её в выбранных типах, в папку со страницы «Скачать». Нажмите на обложку, чтобы увидеть название книги, имя автора, название серии и обложку крупнее.

## Командная строка

```bash
ficbook-dl https://ficbook.net/readfic/1
ficbook-dl 1 13340733 -o ~/Stories --delay 2 --format epub,fb2
```

Подойдёт и ссылка на отдельную часть. Адрес вида `https://ficbook.net/readfic/<id>/<part>` всё равно сохраняет весь рассказ. Можно передать и сам номер работы, без полного адреса.

Файлы попадают в папку `stories/`, если не указан `--out`. `--format` принимает `txt`, `epub` и `fb2`. По умолчанию создаются все три. Имя файла: `Название — Автор.txt`, `.epub` и `.fb2`.

`--out` задаёт папку. `--delay` — пауза между запросами в секундах. По умолчанию 1,5 секунды.

Пока идёт загрузка, в терминале печатается каждая часть, а в конце строка о сохранении файла. На русском это «сохранено …».

Текстовый файл выглядит так:

```
Название
Автор: Имя
https://ficbook.net/readfic/<id>
Серия: Название серии (2)
Фэндом: ...
PG-13 · Завершён
Метки: ...

Описание

Название части

Текст части
```

В следующий раз откройте терминал, перейдите в папку проекта и снова выполните `source .venv/bin/activate`, затем `ficbook-gui`. Когда окружение активно, в начале строки приглашения обычно видно `(.venv)`.

## Ограничения

Текст должен быть доступен на публичной странице. На компьютере, если сайт показывает проверку возраста или у части нет текста, эта работа пропускается, и программа переходит к следующей ссылке. На телефоне приложение показывает проверку возраста, чтобы вы её подтвердили. Оставляйте паузу между запросами, чтобы не нагружать сайт. Пауза по умолчанию — 1,5 секунды.
