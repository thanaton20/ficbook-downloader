# ficbook-downloader

[English](README.md) | Русский

Консольная программа и окно для macOS и Windows. Сохраняет рассказы с [ficbook.net](https://ficbook.net/) в текст UTF-8, EPUB и FB2.

Вы передаёте ссылки на работы. Программа открывает публичную страницу рассказа, проходит по списку частей и записывает по одному файлу каждого формата. Каждая часть становится отдельной главой. В файле есть автор, переводчик, название и номер серии, фэндом, метки и описание. Если у работы есть обложка, она тоже попадает в файл. Между запросами программа ждёт. Браузер не нужен.

Обычным HTTP-библиотекам ficbook отвечает проверкой безопасности. Это приложение использует [curl_cffi](https://github.com/lexiforest/curl_cffi), чтобы запрос выглядел как обычное соединение браузера и в ответ приходила публичная страница рассказа.

## Установка

```bash
cd ~/Developer/ficbook-downloader
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

Если каталог проекта уже есть и окружение создано, достаточно активировать его:

```bash
cd ~/Developer/ficbook-downloader
source .venv/bin/activate
```

Установка прямо из репозитория:

```bash
pip install git+https://github.com/thanaton20/ficbook-downloader.git
```

## Окно

На macOS, после установки:

```bash
ficbook-gui
```

На Windows, из папки проекта:

```bat
.venv\Scripts\activate
ficbook-gui
```

Та же форма открывается командой `ficbook-dl --gui`. В заголовке окна написано **Ficbook Downloader**.

1. В поле **Story links** вставьте по одной ссылке на строку. Подойдёт и номер работы. Ссылка на одну часть всё равно сохраняет весь рассказ.
2. **Save to** — папка `Stories` в домашнем каталоге. Кнопка **Browse** выбирает другую папку.
3. В блоке **Formats** отмечены **TXT**, **EPUB** и **FB2**. Снимите галочки с форматов, которые не нужны.
4. **Pause (seconds)** — пауза между запросами. Сначала там `1.5`.
5. Нажмите **Download**. Кнопка сменится на **Stop**. В журнале под ней печатается каждая часть, а затем строка `saved …` для каждого файла.

Строка рядом с кнопкой в конце показывает, сколько работ сохранено. **Stop** останавливает загрузку перед следующей частью. Уже записанные файлы остаются на месте.

Каждая работа сохраняется как `Название — Автор` с выбранными расширениями.

## Командная строка

```bash
ficbook-dl https://ficbook.net/readfic/1
ficbook-dl 1 13340733 -o ~/Stories --delay 2 --format epub,fb2
```

Подойдёт и ссылка на отдельную часть. Адрес вида `https://ficbook.net/readfic/<id>/<part>` всё равно сохраняет весь рассказ. Можно передать и сам номер работы, без полного адреса.

Файлы попадают в папку `stories/`, если не указан `--out`. `--format` принимает `txt`, `epub` и `fb2`. По умолчанию создаются все три. Имя файла: `Название — Автор.txt`, `.epub` и `.fb2`.

`--out` задаёт папку. `--delay` — пауза между запросами в секундах. По умолчанию 1,5 секунды.

Пока идёт загрузка, в терминале печатается каждая часть, а в конце строка `saved …`.

Текстовый файл выглядит так:

```
Название
Author: Имя
https://ficbook.net/readfic/<id>
Series: Название серии (2)
Fandom: ...
PG-13 · Завершён
Tags: ...

Описание

Название части

Текст части
```

В следующий раз откройте терминал, перейдите в папку проекта и снова выполните `source .venv/bin/activate`, затем `ficbook-gui`. Когда окружение активно, в начале строки приглашения обычно видно `(.venv)`.

## Ограничения

Текст должен быть доступен на публичной странице. Если сайт показывает проверку возраста или у части нет текста, эта работа пропускается, и программа переходит к следующей ссылке. Оставляйте паузу между запросами, чтобы не нагружать сайт. Пауза по умолчанию — 1,5 секунды.
